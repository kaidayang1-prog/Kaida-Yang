# 可点击原型 · Clickable prototype

`index.html` 是一个单文件的手机界面原型，用演示数据把主要流程串起来。它还不是正式的 Next.js 应用。

**打开方式**：直接用浏览器打开 `index.html`，建议用手机或开发者工具的手机尺寸。

**可以演示**：发现与筛选、报名（地址联想）、关注车主、车主接受/拒绝（满座后不能再接受）、路线调整与手动公里数、逐段油费分摊（最大余数法）、PIN 上车、群聊快捷短语、SOS 确认、分享链接、代买清单与超预算提示、账单“我已付款 / 确认收款”、双向评分与整洁度、申诉证据校验、管理后台、中英切换。

右上角可以切换演示身份：乘客 Amy / 车主 Lily / 管理员。
